# Drifter branding

Drifter's mark is a quiet open book with a small current line: reading records
remain distinct while they flow between services. Use the color mark on warm
paper; use the monochrome mark when color is unavailable or the surrounding
surface already carries color.

- Color mark: [`docs/branding/brand-mark.svg`](branding/brand-mark.svg)
- Monochrome mark: [`docs/branding/brand-mark-mono.svg`](branding/brand-mark-mono.svg)
- Browser icon: `internal/httpserver/assets/favicon.svg`

The interface palette pairs ink (`#24423f`) and muted teal (`#2d766e`) with
warm paper (`#f5efe4`, `#fffaf1`). Keep the name Drifter visible beside
non-interactive marks; the mark is decorative, not a substitute for a label.

Use plain, precise language. Describe inspection, review and explicit mapping;
do not imply automatic identity, provider status writes, background syncing, or
features that are not implemented. Optional line: “Keep your reading
connected.” Prefer no slogan over adding it to every surface.
